
# PDVMais  

POS application planned to be a SaaS for Brazilian restaurants and diners.
# FEATURES
Features being worked on are:

- Online menu that can be seen through a qrcode/link provided to the customer
- Online requests based on menu (customer direct)
- POS for an employee to be able to register purchases
- Secondary screen to the bar and kitchen check requests and quickly answer
- Payment performed either on POS or on Online menu
- PIX, debit and credit card integrations
- Stock management
- Multi tenant

# Content
The project has 5 different folders, each for a part of the system:
- backend: has the APIs being used for the system
- db: Contains the database creation and maintenance scripts
- kds: Contains the code for the kitchen display feature
- menu: Contains the code for the online menu feature
- pdv: Contains the code for the POS feature
